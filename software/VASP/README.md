# [VASP](/software/VASP)

Recipes for installing VASP to work with CHTC systems.

> [!IMPORTANT]
> VASP is a licensed software and CHTC **cannot provide the source code**.
> You must obtain your own copy of VASP via your research group's license.
>
> For more information, see [the licensing page](https://vasp.at/sign_in/registration_form/).

Program overview: [vasp.at/info/about/](https://vasp.at/info/about/)

> The Vienna Ab initio Simulation Package (VASP) is a computer program for atomic scale materials modelling,
> e.g. electronic structure calculations and quantum-mechanical molecular dynamics, from first principles.

## Recipes

* [hpc-modules](/software/VASP/hpc-modules): Install VASP on HPC using the system modules
